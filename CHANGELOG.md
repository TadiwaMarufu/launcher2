# Changelog

All notable changes to **EmoLauncher** will be documented in this file.

## [1.0.0] - 2026-08-27
### Added
- Initial production release of EmoLauncher for Android 10+.
- Liquid Glass physical material system with dynamic blur, specular highlights, and refraction shaders.
- Precision Clock system featuring Orbital Circle with traveling second dot, Minimal Text, Unix Timestamp, and Analog Hybrid.
- Customizable Terminal Prompt header (`┌─(emo㉿kali)-[~]\n└─$`).
- Universal Search & Command Palette with direct math evaluation, app search, and system settings triggers.
- Gemini 3.5 Flash Search Grounding integration for real-time question answering.
- Built-in `emo-sh` Unix terminal shell with `neofetch`, `apps`, `launch`, `calc`, and `ai` commands.
- Smart App Drawer with auto-categorization (Dev, Tools, Media, Social, System, Games, Starred, Private).
- Contextual App Long-Press Action Sheet (Pin to Home, Add to Dock, Rename, Hide, App Info, Uninstall).
- Customization Center with real-time live preview and full JSON backup/restore.
