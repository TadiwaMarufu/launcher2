# Contributing to EmoLauncher

We welcome contributions from developers, designers, and terminal enthusiasts!

## Guidelines
1. **Scope Discipline:** Keep additions aligned with minimal friction and maximum personal configurability.
2. **Code Style:** Use modern Kotlin idioms and Jetpack Compose state hoist patterns.
3. **Testing:** Verify local unit tests using Robolectric before submitting pull requests.

## How to Submit Changes
1. Fork the repository
2. Create your feature branch (`git checkout -b feature/orbital-theme`)
3. Commit your changes (`git commit -m 'feat: add orbital theme preset'`)
4. Push to the branch (`git push origin feature/orbital-theme`)
5. Open a Pull Request
